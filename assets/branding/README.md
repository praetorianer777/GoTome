# Branding

The product name is written **GOtome**. Identifiers keep their own spelling: the
binary `gotome`, the Go module path, `GOTOME_*` variables, the repository URL.

| File | Use |
|---|---|
| `banner.png` | Top of the repository README |
| `logo.png` | Logo with wordmark |
| `icon.png` | The logo's mark alone, square; source for the favicon and app icons (#82) |
| `artwork.png` | Illustration for the web app's login and setup pages (#82) |

The files are cut from a 1024 px sheet of drafts, so each is about 340 px wide.
That is enough for a favicon and a README banner; larger uses need a redraw or a
higher-resolution original.

The gopher is based on the Go gopher, designed by Renée French and licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
